### Проект: Выявление профилей потребления в интернет-магазине товаров для дома и быта.
📊 О проекте
Проект по анализу клиентской базы и сегментации покупателей по профилям потребления для формирования персонализированных маркетинговых рассылок. Цель персонализированных маркетинговых рассылок: увеличение среднего чека, частоты покупок и возвращаемости клиентов.

Задачи проекта:

 - На основе данных о транзакциях провести сегментацию покупателей по профилям потребления

 - Выявить наиболее ценные сегменты клиентов

 - Разработать персонализированные стратегии коммуникации для каждого сегмента

Определить оптимальные каналы и содержание рассылок для разных групп клиентов

📁 Данные
Входные данные содержали информацию о транзакциях за 2019 год:

date — дата заказа

customer_id — идентификатор покупателя

order_id — идентификатор заказа

product — наименование товара

quantity — количество товара в заказе

price — цена товара

🛠️ Технологии и методы
Язык программирования: Python

Библиотеки: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, SciPy

Методы: RFM-анализ, кластеризация (K-Means), статистический анализ, визуализация данных

Инструменты: Jupyter Notebook, Git
